# H24-Lab

> Enterprise Active Directory Lab built with PowerShell, Windows Server and Azure.

## 📖 About

H24-Lab is my personal learning project where I build and automate a complete enterprise Active Directory environment.

The goal is not only to learn Windows Server, but also to automate infrastructure using PowerShell and follow real-world administration practices.
